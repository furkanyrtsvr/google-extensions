ℹ Teknik Dokümantasyon

1. Hat Genişliği (IPC-2152)

Area = Width × Thickness

I = k · ΔT^0.44 · A^0.725 k ≈ 0.048, ΔT: Temp Rise, A: Area

2. Via Kapasitesi

A = π · (r_out² - r_in²)
I = k · ΔT^0.44 · A^0.725

3. Clearance (Aralık)

V_peak = V_rms · √2 (for AC)
Final = Base · Multiplier

4. Diferansiyel Çift

k = e^(-2.9 · s / h)
Z_diff = 2 · Z0 · (1 - k)

5. Kayıp Analizi (Loss)

R = ρ · L / A
V_drop = I · R
P_loss = I² · R
