# Bakım ve yayın araçları

Bu klasör dört eklentinin ortak geliştirme ve yayın dosyalarını toplar:

- `docs/`: Sürüm rehberi, taşıma kaydı ve geçmiş ZIP doğrulamaları.
- `scripts/`: Bağımsız sürüm seçimi, GitHub Release ve kurulum ZIP araçları.
- `tests/`: Sürüm bağımsızlığı ve paketleme kontrolleri.

[Sürüm ve geliştirme rehberi](docs/SURUMLEME.md) · [Eklentilere dön](../README.md)

GitHub Actions giriş dosyası GitHub’ın gerekli konumu olan `.github/workflows/` altında kalır. Eklentilerin kendi README, görsel ve kontrol dosyaları kendi klasörlerindedir.
